# Changelog

All notable changes to NexusNotes will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

---

## [Unreleased]

### Added
- Initial project structure and architecture
- FastAPI backend with JWT authentication
- React + TypeScript + Vite frontend
- MySQL database with Alembic migrations
- Note CRUD operations with Markdown support
- Wiki-style note linking (`[[Note Title]]`)
- Backlinks system
- Knowledge graph visualization (D3.js)
- Full-text search
- Folder organization
- Tags system
- Note favorites and archive
- Note revision history with autosave
- Image upload with S3/MinIO storage
- Basic image editing (crop, resize, rotate, flip, brightness, contrast)
- Command palette (`Ctrl/Cmd + K`)
- Keyboard shortcuts
- Dark/light theme support
- Responsive layout (desktop, tablet, mobile)
- Docker Compose development environment (with MinIO)
- Production Docker setup with Nginx
- GitHub Actions CI/CD pipeline
- AWS deployment documentation (EC2, S3, ECR, IAM, CloudWatch)
- Comprehensive documentation
